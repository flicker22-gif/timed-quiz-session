# 限时在线测验系统

## 运行

```bash
python3 app.py          # 依赖: flask (pip install flask)
```

浏览器打开 <http://127.0.0.1:5000/> 创建考试：填标题、时长、学生名单、题目（单选题自动判分，简答题由老师评分，可设满分分值，默认 5 分）。保存后是**草稿**，到管理后台（`/exam/<id>`）校对题目，确认无误点"发布考试"，之后把每个学生的链接发出去。

## 规则

- 考试分**草稿 / 已发布**两种状态：草稿可反复改题、改时长、增减学生；发布后不可修改、不可撤回（系统没有撤回接口）
- 只有**已发布**的考试，学生打开链接才能进场；草稿期打开会提示到"尚未发布"提示，不会计时
- 学生**第一次打开链接**即开始倒计时，截止时间由服务器计算，改本地时间没用
- 发布时为每个学生随机生成一份**互不相同的题目顺序**（存库固定），防止邻座瞟题号；本人刷新、断网重连、换设备打开看到的顺序都不变；只有 1 道题时不打乱
- 答案始终按题目 id 存取，显示顺序打乱不影响判分；老师后台的题目列表和"每题统计"一律按建卷时的原始题号展示/聚合
- 答题每 5 秒 + 每次改动自动保存；刷新、断网、换浏览器重新打开链接都能接着答
- 每次保存带递增版本号，乱序/重发的旧请求到达服务器会被丢弃，不会覆盖更新的答案
- 到点前端自动交卷；即使学生不交，服务器在下次请求时也会强制收卷（用已保存的答案判分）
- 交卷幂等：重复提交/双击/刷新重交都返回原结果，一个学生永远只有一条答卷记录
- 到点后有 5 秒网络宽限（只用于前端自动交卷请求），之后保存答案一律拒绝

## 判分与成绩发布

- **交卷时客观题（单选）立即计分**；简答题进入"待评分"，不影响收卷流程（超时强收的卷子同样如此）
- 老师在管理后台逐份看到学生的简答题作答，**打分（0~满分）并写评语**，后台实时显示每人的客观分、简答分、总分和待评份数
- 评分幂等：重复提交相同评分不产生副作用；提交不同分值视为改分，直接覆盖；成绩发布后仍可改分，学生刷新即看到更新
- **成绩在老师点"发布成绩"前对学生完全不可见**：交卷响应、刷新状态接口都不含任何分数；发布后学生刷新自己的链接，只能看到**本人**的总分、各题得分和评语
- 发布成绩幂等：重复发布返回 `already: true`，不会产生第二次发布
- 正确答案永不下发给学生端（成绩发布后也不给）；学生接口按 token 隔离，任何人只能看到自己的成绩

## 旧数据兼容

- 老版本 `quiz.db` 启动时自动补列（`exams.results_published_at`、`attempts.grading`），存量考试和答卷不受影响
- 老考试同样适用新规则：成绩默认不公开，老师在管理后台点"发布成绩"后学生才可见；老简答题没有满分设置时按默认 5 分评分

## 文件

- `app.py` — 全部后端 + 三个页面（创建页 `/`、学生答题页 `/s/<token>`、管理后台 `/exam/<id>`）
- `test_flow.py` — 端到端测试
- `quiz.db` — SQLite 数据（首次运行自动创建）
